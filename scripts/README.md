# Pasta `scripts`

Aqui ficará o arquivo R final:

`analise_agro.R`

## Ordem recomendada do código

1. Identificação exigida pela FIAP.
2. Pacotes utilizados.
3. Leitura do Excel.
4. Conferência inicial da base.
5. Seleção da variável quantitativa.
6. Tendência central.
7. Dispersão.
8. Separatrizes.
9. Histograma.
10. Boxplot.
11. Seleção da variável qualitativa.
12. Tabela de frequências.
13. Gráfico de barras.

## Primeira linha

A atividade exige um comentário de identificação no formato informado no enunciado, por exemplo:

```r
# NomeCompleto_RMxxxxx_faseX_cap7
```

O grupo deve confirmar como registrar todos os integrantes sem remover essa identificação obrigatória.

## Regra de trabalho

Não escrever o script completo antes de validar a planilha. O R deve trabalhar sobre a base final, não sobre dados provisórios.
