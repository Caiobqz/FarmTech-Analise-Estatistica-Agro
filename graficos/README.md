# Pasta `graficos`

Os gráficos gerados pelo R podem ser salvos aqui para revisão do grupo.

## Esperados

- `histograma.png`
- `boxplot.png`
- `grafico_qualitativo.png`

## Conferência

Todo gráfico deve ter:
- título;
- variável identificada;
- eixos legíveis quando aplicável;
- categorias sem cortes no texto;
- valores coerentes com a base.

Os gráficos desta pasta são auxiliares para revisão. O código que os gera deve permanecer no arquivo R.
