# Guia de aprendizado

Este projeto foi organizado para acelerar tarefas mecânicas sem transformar a atividade em copiar e colar.

## O que já pode ficar pronto sem prejudicar o aprendizado

- estrutura do repositório;
- escolha e documentação da fonte;
- definição de uma estratégia de 30 registros;
- modelo vazio da base;
- dicionário das variáveis;
- checklist de validação;
- roteiro de coleta;
- estrutura comentada do arquivo R;
- organização das etapas;
- revisão técnica depois que o grupo fizer os cálculos.

## O que deve ser feito por você/grupo

Estas etapas fazem parte do conteúdo que precisa ser aprendido:

### Coleta
Você deve abrir o SIDRA, configurar a consulta e conferir o que está sendo baixado.

### Classificação das variáveis
Você deve conseguir justificar os quatro tipos de variável sem decorar uma resposta.

### R
Você deve escrever ou completar os comandos de:
- importação;
- média;
- mediana;
- moda;
- variância;
- desvio padrão;
- quartis;
- histograma;
- boxplot;
- tabela de frequências;
- gráfico qualitativo.

O arquivo `scripts/analise_agro.R` traz a ordem e dicas, mas não entrega a solução completa.

### Interpretação
O grupo deve explicar o que cada medida significa nos dados reais. Gerar um número no R sem saber interpretá-lo não conclui a etapa.

## Regra para pedir ajuda

Se travar:
1. mostre o código que tentou;
2. mostre o erro ou resultado;
3. explique o que você esperava acontecer.

A correção deve começar pelo erro e pela lógica. A solução pronta fica para quando a tentativa guiada não for suficiente.
