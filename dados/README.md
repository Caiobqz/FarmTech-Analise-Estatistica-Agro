# Pasta `dados`

Esta pasta receberá a base final da atividade.

## Arquivo esperado

`base_agro_fiap.xlsx`

## Regras mínimas

- pelo menos 30 registros;
- pelo menos 4 colunas principais;
- uma variável quantitativa discreta;
- uma variável quantitativa contínua;
- uma variável qualitativa nominal;
- uma variável qualitativa ordinal;
- dados provenientes de fonte oficial;
- período e unidade de medida documentados.

## Proposta inicial de colunas

| Coluna | Tipo |
|---|---|
| Municipio | Qualitativa nominal |
| Numero_Estabelecimentos | Quantitativa discreta |
| Area_Total_ha | Quantitativa contínua |
| Faixa_Area | Qualitativa ordinal |

Esta proposta só deve ser usada depois que os dados escolhidos forem confirmados na fonte oficial.

## Segunda aba recomendada

Criar uma aba `Fonte_e_Dicionario` contendo:
- nome da coluna;
- tipo estatístico;
- descrição;
- unidade;
- ano/período;
- link da fonte;
- regra de transformação, quando houver.
